## Engineering principles

- **Make AI verifiable:** connect important outputs to evidence and evaluate them against clear criteria.
- **Give agents boundaries:** use explicit workflows, bounded retries, and isolated execution where appropriate.
- **Build the system around the model:** reliable APIs, structured data, tests, and observability matter as much as generation.
