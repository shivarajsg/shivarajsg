I build applied AI products across retrieval, agent workflows, evaluation, and backend systems—with a particular interest in making AI behavior measurable and evidence-grounded.

- **Building:** RAG/GraphRAG pipelines, agentic applications, and reliable APIs.

## How I build 🧭

- **Evidence before confidence:** important answers should be traceable to sources and checked against explicit criteria.
- **Boundaries before autonomy:** agents need clear tools, bounded retries, and isolated execution where appropriate.
- **Measure the system, not just the model:** tests, schemas, observability, and failure analysis belong in the design.
